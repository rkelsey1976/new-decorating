## How to use this list

1. **Prioritise free first:** bath.org.uk, Yell, Thomson Local, FreeIndex, Somerset Live, Touch Local, Find Your Local, The Trades of Bath, Bing, Apple Maps, Yelp, Trustpilot, Houzz, Scoot.
2. **Then one or two paid trades sites** if you want leads: TrustATrader or Checkatrade (and optionally Bark, RatedPeople, MyBuilder).
3. **Same NAP everywhere:** New Decorating, 07717 772881, https://new-decorating.co.uk. Use the same description style as `business-summary.md` and `bath-org-uk-listing.md`.
4. **When you’re listed:** You can note the directory in `competitor-backlinks-how-to-check.md` when you recheck your referring domains.
